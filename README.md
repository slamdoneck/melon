# Melon · Sprite Studio

Python 3.12+, Streamlit и официальный SDK Google GenAI. Загрузка нескольких
спрайтов, выбор вложения, диалог с Gemini, показ и скачивание изображений.
Модель получает текст и выбранный спрайт и сама выбирает текстовый ответ или
генерацию изображения. Уточнения и правки используют историю диалога.

## Запуск

Скачайте репозиторий (или выполните `git clone https://github.com/slamdoneck/melon.git`)
и откройте терминал в папке `melon`.

Linux / macOS:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.lock.txt
.venv/bin/streamlit run app.py --browser.gatherUsageStats false
```

Windows (PowerShell):

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe -m streamlit run app.py --browser.gatherUsageStats false
```

Откройте адрес, который покажет Streamlit (обычно `http://localhost:8501`).
В облачной среде рабочая папка — `/workspace/melon`.

Добавьте `GEMINI_API_KEY` через секреты среды до запуска процесса. Значение ключа
не хранится в коде и не вводится в чат. Для локального запуска можно передать ключ
через переменную окружения; также поддерживается `GOOGLE_API_KEY`.
Требуется доступ к `generativelanguage.googleapis.com`.

По умолчанию используется `gemini-3.1-flash-lite-image`, указанная в официальном
README SDK на момент разработки. Можно задать `GEMINI_MODEL` или изменить модель
в боковой панели. Нужна модель, доступная вашему ключу и поддерживающая
мультимодальный диалог с ответами TEXT и IMAGE. Доступность, квоты и оплата
проверяются только настоящим запросом. Смена модели начинает новый диалог.

Спрайты и история хранятся в памяти текущей сессии браузера; после завершения
сессии они исчезают. Скачивайте нужные результаты. В Google передаются только
выбранное вложение, запрос и история текущего диалога. Приложение рассчитано на
личную среду разработки; авторизация для публичного размещения пока не добавлена.

## Проверка

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Тесты проверяют обработку спрайтов, передачу изображения в Gemini, сохранение
контекста, обработку ответов и интерфейс без настоящих API-запросов.
Живую генерацию нужно дополнительно проверить после подключения ключа.
